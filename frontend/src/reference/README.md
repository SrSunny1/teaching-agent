# reference/ —— 参考实现（不是模块）

这个目录**不会被自动注册成模块**（壳只扫 `features/*/`），所以不会出现在左栏。
它纯粹是给大家抄结构用的**样板**。

## heatTreatment —— 全项目的组件样板

本地交互、内联 SVG 绘图、数值模型、注释里写了「组件该怎么写」的四条约定。
**做新模块前先读它。**

| 文件 | 看什么 |
|---|---|
| `Component.tsx` | 组件怎么写：读 artifact、本地交互、调 onSendMessage / onEmitArtifact |
| `model.ts` | 数值模型怎么组织（区间都标了教材出处） |
| `preview.ts` | 样例数据怎么写 |
| `index.ts` | 模块怎么注册 |

> ⚠️ 它是**重构前的版本**，里面提到的路径可能和现在的目录对不上，
> 但**组件的写法没变** —— 照着结构抄即可，不用恢复这个模块。

## pageDemo —— 整页模式的最小示例

从 `features/pageDemo/` 移过来的整页模式骨架（原左栏「示例 · 整页模式」）。
它演示：模块怎么接管整个主区，同时用「智能问答」tab 保留「能看见 Agent 干活」的入口。

| 文件 | 看什么 |
|---|---|
| `Page.tsx` | 整页布局、tab、智能问答入口 |
| `Component.tsx` | 画布模式下的说明卡 |
| `index.ts` | 怎么声明 `page` 和 `preview` |

> 整页模式现在由 `features/module2/`（知识库）实际使用；pageDemo 只作为参考，不再注册。
