# 实验四问答数据集 v1

数据：`qaData.ts`。24条人工整理参考问答，不是模型训练集，不是教师确认的标准答案。核对日期：2026-10-19。

每条包含稳定 id、标准问题、等价问法、检索主题、参考回答、预设易错点、来源标识。来源表保留课件页码或网络链接。新增问法前应确认语义等价；不能把仅包含同一组织名称的问题当作同一问题。

## 课程来源

用户提供的《典型材料的微观组织观察.pptx》，共19页。读取PPTX内的文字对象，以幻灯片顺序为页码；使用第2、5、6、7、8、19页。未复制课件图片。第3、4、9至18页含大量图像，未以文字提取结果替代图片审核。第8页存在1147/1148摄氏度表述差异，本数据集不据此生成工艺温度答案。

回答是摘要与教学解释，不是课件逐字原文。学生易错点为教学设计假设，后续应由老师审核并结合匿名课堂提问验证。

新增10条问答，来源为西安交通大学物理国家级实验教学示范中心的《金相试样制备》课件，以及《材料物理专业实验2》教学大纲中的“学生容易犯的错误”和评分标准。覆盖内容：金相试样制备五步、取样与观察方向、电木粉/聚乙烯镶样差异、粗磨/细磨与换砂纸转90°、抛光粉 W7 粒度、常用腐蚀剂选择、硝酸酒精溶液、腐蚀过深/过浅、划痕来源、制样与观察常见错误。

这些条目是课件文字与大纲条目的教学整理，不是教师逐题审定的标准答案；涉及材料种类和腐蚀条件时仍应以课程讲义原文和教师要求为准。

## 检索规则与范围

标准问题或已确认等价问法经过标点、空格及大小写归一化后直接返回参考回答。模块4在统一聊天入口通过可选的 `answerFromSources` 接口查询同一份数据，展示来源与审核状态，不依赖API Key。右侧资料问答仅提供问题快捷入口及引用资料，不再维护第二个输入框。

未命中且离线时只推荐最多四个相关问题，不将相关条目当作原问题答案；在线未命中返回null，保留原后端课程检索。后端尚未导入该本地数据集，在线自由问法不会自动检索这里的全部内容。聊天消息沿用壳的会话存储行为。本地检索明确标为非模型调用，不新增SSE事件，不影响其他模块。
