## Markdown front matter

每个讲义/大纲文件开头声明来源，`ingest.py` 用它填 metadata：

```markdown
---
source: 课程讲义
doc: 课程讲义·晶体结构与晶体缺陷
experiment: 实验一 晶体结构与晶体缺陷
section: 实验原理
---
```

- `source`：来源大类（教材 / 课程讲义 / 教学大纲 / 任务书）。
- `doc`：具体文档名，检索结果的出处会显示为 `《doc》experiment · section`。
- `experiment` / `section`：默认实验名和章节；文件里的 `## 一、实验目的` 等标题会继续更新 `section`。

## 章节封闭集合

`ingest.py` 会把讲义/大纲里的章节名映射回现有封闭集合：

`实验目的`、`实验原理`、`实验内容`、`实验材料及设备`、`实验仪器设备`、`注意事项`、`实验报告及要求`

新增章节名（例如「知识拓展」「学生容易犯的错误」「评分标准」）在 `SECTION_MAP` 里映射，**不引入新的 section 值**。

## 数值口径

- 教材/教材实验二十的 45 钢回火区间（57–60 / 40–48 / 25–35 HRC）是数值模型的基准。
- 课程讲义《金属材料热处理综合实验》给的是通用碳钢口径（58–65 / 35–50 / 20–30 HRC），入库时已在文中标注差异。
- `simulate_heat_treatment` 仍以教材 45 钢曲线为准；回答具体 45 钢硬度时，不要让通用口径覆盖教材口径。

## 检索阈值

语料从 57 块扩到 116 块后，`search_knowledge.MIN_COVERAGE` 从 0.30 调到 0.50。当前探测结果：库内最低 0.653、库外最高 0.380。改动语料或检索逻辑后必须重跑 `retrieval_probe.py`，不要凭感觉改阈值。
