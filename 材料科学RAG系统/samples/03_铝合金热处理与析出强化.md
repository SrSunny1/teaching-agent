# 铝合金的热处理与析出强化

## 1 变形铝合金分类

变形铝合金按主要合金元素分为若干系列：
- **1xxx**：工业纯铝（Al ≥ 99%），导电导热好，强度低；
- **2xxx（Al-Cu 系）**：2024、2A12，可热处理强化，强度高但耐蚀性差；
- **5xxx（Al-Mg 系）**：5083，不可热处理强化，靠加工硬化，焊接性与耐蚀性好；
- **6xxx（Al-Mg-Si 系）**：6061、6063，可热处理强化，综合性能好，是最常用的结构型材；
- **7xxx（Al-Zn-Mg(-Cu) 系）**：7075、7050，强度最高（7075-T6 抗拉强度可达 570 MPa 以上），但应力腐蚀敏感性高。

可热处理强化的前提是：合金元素在铝中的固溶度随温度降低而显著减小，从而具备固溶—淬灭—时效的基础。

## 2 热处理工艺三步曲

### 2.1 固溶处理（Solution Treatment）
将合金加热到固溶线以上、共晶温度以下的单相区保温，使 Mg₂Si、Al₂Cu、Zn-Mg 相等可溶相充分溶入 α(Al) 基体，随后快速冷却（淬火）得到过饱和固溶体。

关键参数：
- 6061 铝合金固溶温度约 530 ℃，保温时间依截面厚度而定（通常 1–2 h）；
- 7075 采用双级固溶（约 470 ℃ + 480 ℃），以溶解更多可溶相同时避免过烧（ incipient melting）；
- 淬火速率必须足够快（水淬 > 100 ℃/s）以"冻结"过饱和固溶体。淬火速率不足会在晶界析出粗大平衡相，既降低强化效果又恶化耐蚀性，这一区域常称为"淬火敏感区"。

### 2.2 淬火（Quenching）
室温水淬是标准做法。厚大件为减小残余应力与变形，可采用：
- 热水淬（60–80 ℃）；
- 聚乙二醇（PAG）水溶液等聚合物淬火介质；
- 喷淋淬火。

淬火后应立即进入时效，延迟时间越长，自然时效形成的原子团簇越粗化，后续人工时效的强化效果越弱（对 7xxx 系尤其明显）。

### 2.3 时效（Aging）

**自然时效（T3/T4）**：室温放置数天至数周，溶质原子偏聚形成 GP 区。6xxx 系自然时效硬化慢且不稳定，7xxx 系自然时效可持续数年并显著强化。

**人工时效（T6/T7）**：在 100–200 ℃ 保温数小时至数十小时。

6xxx 系（Al-Mg-Si）经典析出序列：
```
过饱和固溶体 (SSSS) → Mg/Si 原子团簇 → GP 区 → β″ (Mg5Si6, 针状) → β′ (Mg1.5Si) → β (Mg2Si, 稳定相)
```
其中 **β″ 相**与基体共格、沿 ⟨100⟩_Al 方向呈针状析出，是峰值强度（T6 状态）的主要贡献者。过时效后 β″ 转变为半共格的 β′，强度下降。

7xxx 系（Al-Zn-Mg-Cu）析出序列：
```
SSSS → GP(I)/GP(II) 区 → η′ (MgZn2, 半共格, 强化主相) → η (MgZn2, 稳定相)
```
η′ 是峰值时效（T6）的主要强化相；T7（过时效）牺牲约 10–15% 强度，换取显著改善的抗应力腐蚀开裂（SCC）性能。

## 3 强化机制定量

析出强化的贡献主要来自位错与析出粒子的交互，分两种机制：

1. **切过机制（cutting）**：析出相细小（半径 < 临界值）且与基体共格时，位错切过粒子，强化贡献来源于共格应变、模量错配、化学强化（反相畴界 APB）。此时析出相半径越大、体积分数越高，强度越高。
2. **绕过机制（Orowan 绕过）**：析出相粗大到不可切过时，位错绕过并在粒子间留下位错环。Orowan 临界分切应力增量：

   Δτ = (G·b) / (2π·λ·√((1-ν))) · ln(r/b)

   其中 G 为剪切模量，b 为柏氏矢量，ν 为泊松比，λ 为粒子间距，r 为粒子半径。粒子越细密（λ 越小），强度越高。

强度随析出相尺寸呈"先升后降"，峰值出现在切过→绕过机制的转折点附近，这就是 T6（峰值时效）的物理含义。

## 4 常见缺陷与控制

- **过烧**：固溶温度过高导致晶界低熔点共晶局部熔化，形成复熔球与晶界氧化，材料报废不可补救；
- **粗晶环**：挤压型材表层因剧烈变形与高温再结晶形成粗大晶粒层，降低疲劳性能；
- **晶间腐蚀与剥落腐蚀**：7xxx 系晶界析出 η 相（MgZn₂）形成阳极通道，需通过 T7 过时效或回归再时效（RRA）使晶界析出相粗化、断续分布；
- **回归再时效（RRA, Retrogression and Reaging）**：7075 先在 200–220 ℃ 短时回归（数分钟）使晶内析出相部分回溶、晶界相粗化，再重新 T6 时效，可同时获得 T6 级强度与 T7 级耐蚀性；
- **残余应力**：淬火产生，可通过预拉伸（对板材 1–3% 永久变形）、模冷或振动时效消除。

## 5 状态代号速查

| 代号 | 含义 |
|---|---|
| F | 自由加工状态（无性能限制） |
| O | 退火状态（最软，塑性最好） |
| H | 加工硬化（H1x 纯加工硬化，H2x 加工硬化后部分退火，H3x 加工硬化后稳定化） |
| T3 | 固溶 + 冷加工 + 自然时效 |
| T4 | 固溶 + 自然时效 |
| T5 | 高温成形冷却 + 人工时效（不固溶） |
| T6 | 固溶 + 人工时效（峰值强度） |
| T7 | 固溶 + 过时效（耐蚀优先） |
| T73 | 固溶 + 三级过时效（抗应力腐蚀） |

## 6 表征手段

- **DSC（差示扫描量热）**：识别 GP 区溶解峰（约 150–250 ℃）与 β″/η′ 析出峰，是确定时效制度的核心工具；
- **TEM**：直接观察析出相形貌、尺寸分布与共格关系；
- **电导率**：7xxx 系电导率随时效程度单调升高，工业上常用电导率（%IACS）快速判定是否达到 T73 过时效；
- **硬度（HV/HRB）**：时效曲线的常规监控手段。
