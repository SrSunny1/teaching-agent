1. 凝固、结晶与相变
物质由液态转变为固态的过程称为凝固。
物质由液态转变为晶态的过程称为结晶。
物质由一个相转变为另一个相的过程称为相变。因此，结晶过程是相变过程。
2. 冷却曲线与过冷度
金属结晶时温度与时间的关系曲线称为冷却曲线。曲线上水平阶段所对应的温度称为实际结晶温度 T1；水平阶段是由于结晶时放出结晶潜热引起的。
液态金属在理论结晶温度以下才开始结晶的现象称为过冷。理论结晶温度与实际结晶温度之差称为过冷度：
ΔT = T0 − T1
过冷度大小与冷却速度有关：冷却速度越大，过冷度越大。
结晶的热力学条件：液态与固态的体积自由能都随温度升高而降低；液相熵值更高，因此液相自由能随温度升高下降得更快；固相内能更低，低温下固相自由能更低。两条自由能曲线在平衡结晶温度 Tm 处相交。
金属结晶的驱动力由过冷提供：过冷度越大，结晶驱动力越大；过冷度为零时驱动力不存在，液态金属不会在没有过冷度的情况下结晶。
3. 结晶的结构条件
液态金属中存在原子排列规则的小原子团，时聚时散，称为晶坯。
在 T0 以下经过一段时间（孕育期），一些大尺寸晶坯会长大成为晶核。晶核尺寸必须大于临界值才能继续长大。
结晶由晶核的形成和晶核的长大两个基本过程组成。
4. 形核
形核有两种方式：
- 均匀形核：由液体中排列规则的原子团形成晶核。
- 非均匀形核：以液体中存在的固态杂质为核心形核。非均匀形核更为普遍。
5. 晶体长大与晶粒大小
晶体长大有均匀生长和树枝状生长等形态。
晶粒大小会影响性能，例如强度、韧性、导电性。各要素之间互相制约、互相影响。
6. 知识拓展：非晶与高熵合金
如果晶体在性能上有缺陷，那么不结晶或紊乱程度很高的材料会怎样？答案是非晶和高熵合金。
高熵非晶合金具有超高强度和硬度、无疲劳极限、耐腐蚀、低导电、低导热等特点，并在催化、储氢等方向有应用前景，是新材料体系的重要方向。

本实验用 NH4Cl 水溶液的结晶过程观察来代替金属结晶过程，这是一种“转换法”：用易于观察的透明溶液体系模拟不透明金属的结晶。
观察过饱和 NH4Cl 水溶液在下列条件下的结晶过程与晶体生长形态：
- 培养皿中空冷结晶。
- 生物显微镜下空冷结晶。
- 小烧杯中空冷结晶。
- 试管中空冷结晶。
- 培养皿中撒入少许 NH4Cl 粉末并空冷结晶。
- 培养皿置于冰块上结晶。
- 将冰块投入小烧杯中结晶。
在每个条件下观察结晶开始、晶体长大和结晶完成三个阶段，记录晶核大小、晶体形态和组织粗细。
