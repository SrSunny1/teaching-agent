1. 什么是硬度
硬度是指材料抵抗局部变形，特别是塑性变形、压痕或划痕的能力。它是衡量材料软硬程度的一个指标，反映材料表面抵抗磨损、划伤和压入等破坏的能力。
硬度在工程与制造业中用于保证零件使用寿命；在日常生活与消费品中用于提高产品耐用性；在航空航天与国防领域中用于满足特殊环境需求。
2. 静载压入法
静载压入法是用一定的载荷将规定的压头压入被测材料，以材料表面局部塑性变形的大小比较材料的软硬。由于压头、载荷和载荷持续时间不同，压入硬度有多种标度。
常用三种：
- 布氏硬度（HB）：采用一定直径的硬质合金球，在规定载荷和时间下压入金属表面，测量压痕直径计算硬度值。适用于测量退火、正火、调质处理后的金属材料以及铸铁等较软的金属。
- 洛氏硬度（HR）：根据压头压入被测材料表面的深度确定硬度值。操作简便、迅速，可直接从硬度计表盘读出，适用于各种硬度范围的金属材料，尤其是较硬的金属。
- 维氏硬度（HV）：以相对面夹角为 136° 的正四棱锥金刚石压头，在规定载荷和时间下压入金属表面，测量压痕对角线长度计算硬度值。测量精度高，适用于测量金属材料的表面硬度、微小区域硬度以及不同热处理状态下的硬度。
维氏硬度值 HV 的单位为 kg/mm²；P 为试验力，d 为压痕对角线长度。显微硬度计通常同时显示压痕对角线 d1、d2，并由仪器自动计算硬度值。
3. 显微硬度计
仪器由精密机械、光学系统和专用微处理机组合而成。主要用途有两种：
1. 单独测定硬度：用于测定比较光洁表面的细小或片状零件和试样，测定电镀层、渗碳层、氮化层等表层硬度，以及玻璃、玛瑙等脆性材料和其他非金属的硬度。
2. 作金相显微镜用：观察和拍摄材料的显微组织，并测定相组织的显微硬度。
侧视结构：1 升降旋轮、2 升降螺杆、3 载物台、4 压头、5 物镜、6 试验力选择、7 螺旋测微计、8 目镜。
操作面板功能：
- 标尺：HV、HK 的选择。
- 清零：测试时对 d1、d2 清零。
- 换算：可对 HRC、HV、HL 等进行硬度换算。
- D+、D-：保荷时间的选择。
- L+、L-：灯亮度的选择。
- 返回：返回到前一界面。
- 启动：开始加载荷。
- 自动转塔：切换物镜/压头。
4. 实验步骤
1. 制备试样，抛光表面，制作成金相试样。
2. 选择合适的试验力。
3. 设置保压时间。
4. 转动自动转塔按钮，选择合适的倍数的物镜。
5. 启动加载。
6. 测量压痕尺寸。
7. 输入数据，自动计算硬度值。
